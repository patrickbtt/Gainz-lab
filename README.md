# GainzLab 💪

Site e-commerce de compléments alimentaires développé avec Symfony.

🔗 **Démo en ligne :** https://gainzlab.alwaysdata.net

## Contexte
Projet réalisé en binôme dans le cadre de la L3 MIAGE (Nantes Université), avril 2026,
avec [Georges](https://github.com/georgesdhh).

## Fonctionnalités
- Catalogue produits avec catégories
- Panier et passage de commande
- Authentification utilisateurs
- Espace administration

## Stack
- PHP / Symfony
- Twig
- Doctrine / MySQL
- Déploiement : Alwaysdata
